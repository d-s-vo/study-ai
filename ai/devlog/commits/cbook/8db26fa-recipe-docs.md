# cbook@8db26fa — docs: описание раздела «Рецепты» в README

> Коммит-сообщение (как в клиентском репо): `docs: описание раздела «Рецепты» в README`
> Doc-only пропагация user-visible части FEAT-011 (`6116cff`). 1 файл, +13 строк.

## Кратко (для инженера)

- **`README.md`** — новая секция «🍲 Раздел «Рецепты»» между интро-блоком (с предупреждением о
  миграции) и «Технический стек». Описывает user-visible поведение страниц рецептов из `6116cff`:
  каталог доступен auth+verified пользователям (пункт меню «Рецепты»); список с пагинацией по 12;
  просмотр любого рецепта; создание через форму; редактирование/удаление — только владельцу.

## Детально (для новичка)

Правило проекта: user-visible смена поведения отражается в публичной доке клиента. Код-коммит
`6116cff` (FEAT-011) добавил страницы рецептов и пункт меню, но README не трогал — по спеке
формулировка пункта меню и раздела была помечена «согласовать с владельцем». Согласование прошло
(пункт меню — «Рецепты»), и этот отдельный `docs:`-коммит закрывает пропагацию.

Секция помещена сразу после вводного описания приложения (что делает пользователь) и до
технического стека: README идёт по логике «что → как», и user-facing описание раздела естественно
стоит рядом с интро, а не в «Архитектуре» (та про слои для разработчика) и не в «Доменной модели»
(та про поля сущностей). Формат — маркированный список из четырёх пунктов (список / просмотр /
создание / редактирование-удаление), тон нейтральный продуктовый, в стиле остального README
(эмодзи в заголовке секции — как у соседних).

Ключевой факт прав доступа сформулирован по-пользовательски: чужие рецепты видны для просмотра, но
кнопки правки и удаления показываются лишь владельцу — без упоминания Gate/403/резолверов.

## Почему так, а не иначе

- Место — после интро, перед «Технический стек», а не в «Архитектуре»/«Доменной модели»: секция
  описывает поведение для пользователя, а не устройство слоёв или схему полей.
- Отдельный `docs:`-коммит на своей ветке, а не довесок к `6116cff`: код и документация разнесены,
  и правка доки ждала отдельного согласования формулировки пункта меню с владельцем.
- Пагинация названа «по 12 на странице» словами, без ссылок на `meta.*_page_url`/Spatie — деталь
  реализации пользователю не нужна.
- Загрузка изображений в секцию не добавлена: это отдельная возможность из интро, к страницам
  FEAT-011 не относится.
