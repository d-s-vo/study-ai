# ADR-002: Целевой стек — Laravel 12 (PHP 8.4) + MySQL 8 + Filament 5 + Inertia/Vue 3 (TS strict) + Spatie Data

**Статус:** Принят (зафиксирован при инициализации `ai/`)
**Дата:** 2026-07-28

> Продуктовый decision-ADR. Фиксирует целевой стек cbook по уточнённому ТЗ заказчика.
> Обоснование задним числом: описаны реально действовавшие силы и последствия, без выдуманных альтернатив.
> **Уточнение (2026-07-28):** ТЗ заказчика зафиксировало версии/пакеты. Прежние дефолты (Laravel 11 / PHP 8.3 / PostgreSQL / Filament 3) **отменены**; это уточнение того же ADR-002, а не новый номер.

## Контекст

cbook — кулинарная книга (рецепты с ингредиентами, шагами приготовления и изображениями). Легаси-код — Nuxt 4 (Vue 3/TS) с Prisma + PostgreSQL (Neon) и MinIO (S3). Решено вести дальнейшую разработку на серверном фреймворке с сильной «батарейной» экосистемой и готовой админкой, сохранив уже знакомый фронтенд-слой (Vue 3 + TypeScript). Требовалось: быстрый CRUD-бэкенд с аутентификацией/авторизацией «из коробки», админ-панель без ручного написания, единый цельный проект (не разнесённый SPA + отдельный API), воспроизводимое локальное окружение.

## Рассмотренные варианты

### Вариант А — Остаться на Nuxt 4 (fullstack Nitro) + Prisma
- **За:** код уже написан; не нужна миграция; единый язык (TS) на всех слоях.
- **Против:** админку и авторизацию/политики надо строить руками; серверная экосистема тоньше, чем у зрелого backend-фреймворка; выбран отход от этого пути (см. ADR-006).

### Вариант Б — Laravel 12 + Filament 5 + Inertia/Vue 3 + TS strict + Spatie Data (выбран)
- **За:** Laravel даёт auth, очереди, валидацию, миграции из коробки; Filament 5 — готовая админ-панель на политиках доступа; Inertia сохраняет фронт на Vue 3 + TypeScript без отдельного REST-клиента (сервер как источник данных); Spatie Laravel Data даёт типобезопасные DTO с автогенерацией TS-типов (единый контракт front↔back); Laravel Sail — воспроизводимое Docker-окружение.
- **Против:** переписывание (rewrite) cbook с Nuxt на Laravel с нуля (стоимость старта — см. ADR-006); два языка/тулчейна (PHP + TS); PHP-инструменты идут через контейнеры Sail; строгий статанализ (PHPStan L10) требует дисциплины.

## Решение

Целевой стек cbook, в котором ведётся разработка (версии/пакеты — по ТЗ заказчика):

1. **Backend:** **Laravel 12 (PHP 8.4)**, строгая слоистая архитектура (детали — ADR-003). Качество: **PHPStan Level 10** + Laravel Pint (PSR-12, `declare_strict_types`); тесты — **Pest PHP**.
2. **Слой данных:** Spatie **Laravel Data** (DTO) + автогенерация TS-типов (`artisan typescript:transform`) — наружу отдаются только DTO.
3. **Админка:** **Filament 5**, панель `/admin`; Resource'ы без бизнес-логики, делегируют в Task/Repository.
4. **Frontend:** Inertia.js + Vue 3 (`<script setup>`, TypeScript **strict**) + **Tailwind CSS**, сборка Vite; данные приходят DTO-props'ами Inertia (без отдельного публичного API-клиента).
5. **Хранение:** **MySQL 8** (Sail-сервис `mysql`, порт 3306); медиа (изображения рецептов) — пакет **`whyme-agency/laravel-media`**; кэш/очереди — Redis (как есть).
6. **Локальное окружение:** Laravel Sail (Docker), инструмент `./vendor/bin/sail`. Типы фронта — `vue-tsc` (strict) + автоген из Spatie Data; линт — Pint (+ ESLint на фронте).

## Последствия

- Команды/версии стека — единый источник в [`../guides/stack-specifics.md`](../guides/stack-specifics.md); документация значения из скриптов не дублирует.
- Минимальный набор гейтов проекта: тесты (Pest) + статанализ (**PHPStan Level 10**, ловит и нарушение изоляции Eloquent/слоёв) + lint (Pint); после правки DTO — `artisan typescript:transform`; тяжёлые прогоны сериализуются через `gate.sh`.
- Появляется переписывание (rewrite) cbook с Nuxt на Laravel с нуля как первая крупная инициатива (ADR-006); legacy-контур (Nuxt/Prisma/Neon Postgres/MinIO/Cloudflare Tunnel) — донор идеи+BVI, замещается.
- СУБД целевого стека — **MySQL 8**; схема пишется заново под Laravel-миграции (не перенос Prisma-схемы).
- Издержка: два тулчейна (PHP-через-Sail и Node/pnpm), PHP-инструменты доступны только при поднятых контейнерах; строгий PHPStan L10 требует держать Eloquent в репозиториях.
- **Вопрос СУБД снят ТЗ:** MySQL 8. Открытый вопрос: дисковый бэкенд для `whyme-agency/laravel-media` (локальный/S3) — `(уточнить)`.
