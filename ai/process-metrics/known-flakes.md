# `known-flakes.md` — реестр известных флейков тест-гейта

> Durable-память о недетерминированных тестах (флейках). **Сверься с реестром ПРЕЖДЕ, чем диагностировать «новый» падёж теста** (см. [`../guides/process-retro.md`](../guides/process-retro.md) §г, [`../guides/debugging.md`](../guides/debugging.md) §4).

**Дисциплина (не enforcement — реестр не блокирует CI):**
- Тест в реестре со статусом `активен` → повтори прогон / отметь, **НЕ диагностируй с нуля**.
- Теста нет в реестре, но он флейкует → диагностируй и **внеси строку** (`активен` + симптом) — следующий исполнитель не переплатит.
- `починен` — историческая запись: **не удаляется**, чтобы повторный регресс узнавался, а не переоткрывался с нуля.

## Формат

| колонка | смысл |
|---|---|
| `тест` | идентификатор теста/сьюта (имя + файл) |
| `симптом` | наблюдаемое проявление флейка (таймаут / порядок / гонка / утечка env и т.п.) |
| `статус` | `активен` \| `починен` |
| `коммит-фикс` | ссылка на коммит-фикс (для `починен`) или `—` (для `активен`) |
| `дата` | когда внесён / починен (`YYYY-MM-DD`) |

## Реестр

Пусто до первого пойманного флейка. Первая строка появляется, когда тест флейкнул ≥1 раза и это подтвердилось. Пример строки: `` `path/to/test_module.py::test_name` `` · таймаут под полным прогоном · `активен` · `—` · `YYYY-MM-DD`.

| тест | симптом | статус | коммит-фикс | дата |
|------|---------|--------|-------------|------|
| _(пусто — заполняется по мере обнаружения флейков)_ | | | | |
