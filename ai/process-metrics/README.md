# `process-metrics/` — субстрат Process Retro (модуль M7, ОПЦИОНАЛЬНО)

> **Статус: опциональная папка.** Нужна **вместе с** [`../guides/process-retro.md`](../guides/process-retro.md) — только когда в проекте пошли многофичные инициативы через `adr-execution.md`. Для малых проектов не заводи её; по умолчанию модуль отложен (см. `memory.md` — строка «включить при первой крупной инициативе»).

## Назначение

Durable-субстрат самоанализа **процесса** разработки (dev-плоскость, не рантайм продукта). Тут живут три вещи:

- **Метрик-леджер** `adr-NNN.jsonl` — построчные замеры по фичам инициативы (токен-экономика по ролям, петли red→green, merge-конфликты, стадия поимки дефектов, нарушения канонов). Вход ретро-пасса.
- **Ретро-записи** `retro-<инициатива>.md` — человекочитаемый выход ритуала ретро (снимок + срез-вердикты + кандидаты с диспозицией). Шаблон — [`retro-TEMPLATE.md`](retro-TEMPLATE.md).
- **Реестр флейков** `known-flakes.md` — durable-память об известных недетерминированных тестах.

Ни леджер, ни записи **не читаются рантаймом продукта** — это данные для ретро.

## Формат имён файлов

| Файл | Формат имени | Пример |
|---|---|---|
| Леджер инициативы | `adr-<NNN>.jsonl` | `adr-012.jsonl` |
| Ретро-запись | `retro-<инициатива>.md` | `retro-012.md`, `retro-2026-w28.md` (если ретро по волне, не по одному ADR) |
| Реестр флейков | `known-flakes.md` (единственный, на весь проект) | `known-flakes.md` |
| Шаблон ретро | `retro-TEMPLATE.md` (не инстанс — образец для копирования) | `retro-TEMPLATE.md` |

**Один леджер — одна инициатива.** Строки append-only (дописываются в конец, не переписываются) — это делает формат безопасным для параллельных субагентов.

## Чекер полноты (опционально)

Чтобы леджер не пришёл к ретро с дырами — сверяй его **чекером полноты**: на каждую закрытую (`✅`/`⚠️`) фичу инициативы обязана быть строка с ключами `feat`/`adr`/`role`/`model` (проверяется наличие **ключа**, не значения — `null` ОК). Чекер — **warn-only** (не валит CI; `--strict` — локальный опт-ин), считает только закрытые фичи (⬜/🚧 игнорирует), на пустом списке проходит тихо. Идея и роль — в [`../guides/process-retro.md`](../guides/process-retro.md) §б; конкретный скрипт заводится под проект (`# ADAPT:`).
