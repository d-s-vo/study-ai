## Порядок чтения контекста (кэш-стабильный префикс → волатильная дельта)

1. **Свежий worktree → Step-0 ПЕРВЫМ действием** (до чтения контекста): `git merge develop --no-edit` → восстановление зависимостей и codegen (`./scripts/sync.sh && ./scripts/status.sh`; детали — `../stack-specifics.md`). Симптом сталого базиса (нет prereq-кода, который точно смержен) → сделай merge, НЕ считай «фича не начата».
2. [`../../architecture.md`](../../architecture.md) — инварианты, стек (стабильный префикс).
3. Живой документ инициативы (ADR): сквозные требования + keystone-контракты + **СТРОКА своей фичи** + последние записи журнала (заметки предыдущих субагентов) — читаешь **ПОСЛЕДНЕЙ** (волатильная дельта).
4. `spec.md` своей фичи (должна уже существовать по specs-first; нет — напиши + тройная проверка).

## Работа

- В **отдельной ветке + git worktree** (изоляция), строго по [`../feature-workflow.md`](../feature-workflow.md): baseline зелёный → реализация снизу-вверх (контракт/схема → логика → сервисы → тесты) → DoD (тесты + typecheck + lint + build) → живая приёмка.
- Сквозные требования инициативы — **часть Acceptance Criteria**, не полиш.
- **File-ownership fence.** Правь только файлы **своей** фичи. Не трогай файлы, принадлежащие параллельным фичам. В живом документе ADR редактируй **только СВОЮ строку** статуса + **дописывай** строку журнала (append-only) — не переписывай чужие строки и не правь keystone-/сквозные разделы напрямую (иначе — merge-конфликт и потеря чужой работы).
- **Keystone-дельту возвращай ТЕКСТОМ оркестратору, не применяй сам.** Нужно изменить общий контракт/keystone (схему, разделяемый интерфейс, сквозной инвариант)? Не редактируй его в одиночку — **опиши дельту в сводке** возврата; оркестратор применит её в одной точке и разошлёт остальным. Так контракт не форкается по параллельным веткам.
- Обнови **живой документ** (статус фичи в таблице + строка в журнале с заметками для будущих фич) — иначе фича НЕ завершена.

## Возврат оркестратору — сжатая сводка (это ДАННЫЕ, не сообщение пользователю)

**≤150 токенов, только дельта состояния — не пересказ протокола:**

```
FEAT-NNN: ✅ | ⚠️(отклонение) | ❌(заблокирован)
что сделано: 1-2 строки
живой документ: статус ✓ / журнал ✓
keystone-дельта: <нет / контракт X: было→стало — ТЕКСТОМ, чтобы оркестратор применил>
гейты: тесты N pass 0 fail; typecheck/lint/build ✓
заметки оркестратору: что разблокировано / риски / нужна ли пере-декомпозиция
отклонения от spec: <нет / кратко>
```
