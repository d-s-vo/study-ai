# ai/coord — координационный слой параллельной работы агентов

Состояние координации нескольких агентов, работающих в одном workspace под **разными**
сессиями/аккаунтами. Общее у агентов — только файловая система: вся синхронизация идёт через файлы
здесь и mkdir-мьютексы. Действует и в single-agent режиме (изоляция стенда для приёмки своего кода —
см. `../guides/coordination.md`).

## Каталоги

| Каталог | Назначение | Git |
|---------|-----------|-----|
| `agents/` | Файлы присутствия живых сессий `<session_id>.json` (pid, аккаунт, heartbeat) | эфемерное, **не коммитится** (`.gitignore`) |
| `locks/`  | Каталоги-мьютексы `<имя>.lock` (mkdir-локи с owner-файлом) | эфемерное, **не коммитится** |
| `bookings/` | Активные брони фич `<slug>.json` (FEAT/ADR/репо/ветка/порты/статус) | **коммитится** (общая доска) |
| `archive/` | Брони закрытых (merged) фич | **коммитится** (история) |
| `fetch-state.json` | Маркер привилегированного fetch (K-fetch); в этом профиле модуль M5 выключен — маркер не используется | эфемерное, **не коммитится** |

Разделение принципиально: **эфемерное присутствие** (`agents/`, `locks/`, `fetch-state.json`) живёт
только на диске текущего рабочего дерева и пересоздаётся при старте сессии; **доска бронирования**
(`bookings/`, `archive/`) — общее знание команды агентов, поэтому коммитится и синхронизируется через
`scripts/sync.sh` как обычные файлы репозитория.

## Инструменты

- `scripts/coord.sh` — `agents` / `board` / `book` / `update` / `unbook` / `reap`
- `scripts/gate.sh` — сериализация тяжёлых операций между агентами
- `scripts/ai-commit.sh` — коммит своей зоны в `study-cbook-ai` под локом `shared-docs`
- хуки `githooks/coord-*.sh` — присутствие/heartbeat (регистрируются в `.claude/settings.json`)

**Правила и жизненный цикл** — [`../guides/coordination.md`](../guides/coordination.md).
