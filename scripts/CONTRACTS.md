# scripts/CONTRACTS.md — контракты стеко-зависимых скриптов

В этом профиле модули **M3 (quality-ratchet)** и **M4 (env-isolation)** ВЫКЛЮЧЕНЫ: скрипты
`env-for-task.sh`, `quality-gate.sh`, `quality-report.sh` не разворачивались и в репозитории
отсутствуют. Их контракты (вход/выход/инварианты) здесь не документируются — при включении
модулей контракты фиксируются заново под стек проекта (см. `ai/guides/stack-specifics.md`).

Деградация в отсутствие модулей:
- **M4=OFF** — изолированного стенда на задачу нет; приёмка своего кода идёт на эфемерной
  тестовой БД/фикстурах (Sail: `.env.testing` + `RefreshDatabase`), свой порт при необходимости —
  вручную. См. `ai/guides/live-acceptance.md`.
- **M3=OFF** — принуждение качества не автоматизировано; в `feature-workflow` действует
  минимальный набор гейтов вручную: тесты / typecheck / lint (pint), тяжёлые прогоны — под
  `gate.sh <ресурс>` для сериализации между агентами.

Общий инвариант, актуальный независимо от модулей:
- Тяжёлые операции (полный прогон тестов, сборка, дорогой линт) — под `gate.sh <ресурс>` для
  сериализации RAM/CPU между агентами.
