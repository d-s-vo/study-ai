# allowpatterns.txt — допуски (whitelist) охранной обвязки клиентских хуков.
# Одна regex (grep -E) на строку. Пустые строки и '#'-комментарии игнорируются.
# Если СТРОКА, на которой сработал стоп-словарь, дополнительно матчит любой из этих
# паттернов — совпадение игнорируется (легитимный контент клиентских реп).
# Скан кейс-инсенситивный.
#
# Легитимные "agent" (стоп-словарь голое agent НЕ содержит, но на всякий случай):
user-agent
useragent
user_agent
#
# Дифф-заголовки и упоминания легитимных AGENTS.md заказчика:
\+\+\+ b/.*AGENTS\.md
--- a/.*AGENTS\.md
diff --git .*AGENTS\.md
#
# Легитимные feature-конструкции заказчика (флаги/ветки/тумблеры) — не путать со следом
# FEAT-номеров; строка с ними исключается из срабатывания:
feature[-_ ](flag|flags|branch|toggle|toggles|test|spec)
# 'orchestration' (k8s/devops) — легитимно; стоп-слово 'orchestrator' её не ловит,
# но перестрахуемся на случай узких форм в тексте.
orchestration
#
# --- плейсхолдеры шаблона (чтобы {{...}} в примерах не считались нарушением) ---
\{\{[^}]*\}\}
